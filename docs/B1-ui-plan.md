# Second Take — B1 UI plan

## Listener screen
1. Choose one of two listener presets or enter a custom profile.
   Mark presets as provisional until the official profiles are confirmed.
2. For a custom profile, enter language, topics, depth and time budget.
   Show a loading message, and offer a retry if generation fails.
3. Show the listener summary, edition date and an audio player when audio
   is available. Visibly disclose that the voice is synthetic.
4. Show the transcript in playback order with clickable source titles
   next to each factual sentence.

## First build
- Use the shared API contract and synthetic briefing fixture.
- Label fixture mode “Synthetic example — not a news briefing.”
- If the fixture has no audio, show “No audio in this preview.”
- Keep the returning-listener feature out of the first build.

## Demo and checks
- Compare two complete briefings with different stories, order or depth.
- Play an excerpt and click through from a spoken claim to its source.
- Test an unseen custom profile with fresh generation.
- Verify three spoken claims against their linked articles before the demo.
